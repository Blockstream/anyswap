# SDK docs

The docs site of both SDKs, built with [Docusaurus](https://docusaurus.io/)
and published at <https://blockstream.github.io/anyswap/>.
`docs/typescript/reference/` is generated by `npm run docs:generate` in
`ts-sdk/`.

To serve it locally with Node.js `22+`, from this directory:

```bash
npm ci
npm start
```

`npm run build` builds the site into `build/` and fails on a broken link or
anchor.

## Writing a page

A page is `.mdx` and written once for both SDKs. The navbar switch picks the
language, and these components follow it:

| Component | Use |
|---|---|
| `<Code>` holding a `<Rust>` and a `<Ts>` | one snippet per language, each a fenced code block |
| `<Id rust="min_confs" ts="minConfs" />` | an identifier spelled differently per language |

A page states what the integrator does, sees and relies on: statuses,
outcomes and rules, never how the driver reaches them.
